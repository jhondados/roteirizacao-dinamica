# 🚚 Roteirização Dinâmica

> Roteirização dinâmica em tempo real com IA. Reotimiza rotas conforme novos pedidos, trânsito e imprevistos durante a operação.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/roteirizacao-dinamica/

## 📊 Resultados-chave (KPIs)
**+26%** Eficiência · **< 5s** Reotim. · **reativo** Pedidos · **-21%** Custo

## 🧠 Tecnologias de IA
Real-time Optimization · ML · OR-Tools

## ✨ O que faz
- Reotimização em tempo real
- Inserção dinâmica de pedidos
- Resposta a imprevistos
- Balanceamento de carga

## 🗄️ Fonte de dados real
[Pedidos + trânsito](https://www.gov.br/antt)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Pedidos + trânsito
2. **Processamento com IA** — Real-time Optimization · ML · OR-Tools
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
